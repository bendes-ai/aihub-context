# aihub-context

Wissenspaket über den persönlichen KI-Hub (AIHub) auf einem NAS. Es ist für **KI-Assistenten ohne Gedächtnis** gedacht, zum Beispiel Perplexity, wenn man dort nicht angemeldet ist und der Hub nur die Frage übergeben kann.

| Datei | Inhalt |
|---|---|
| [CONTEXT.md](CONTEXT.md) | Kurzfassung zum Einfügen oder Verlinken (ca. 380 Wörter) |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Container, Datenwege, Gehirn, Ideen, MCP |
| [DECISIONS.md](DECISIONS.md) | Entscheidungen mit Begründung, nach Datum |
| [STATUS.md](STATUS.md) | Stand, offene Punkte, bekannte Schwächen |

## So benutzt du es
- **Einfügen**: `CONTEXT.md` kopieren und der Frage voranstellen.
- **Verlinken**: Ist das Repo öffentlich lesbar, genügt der Satz „Lies zuerst `<Repo-URL>/blob/main/CONTEXT.md`“. Ein privates Repo kann Perplexity ohne Anmeldung nicht lesen.

## Pflege
Die Dateien sind von Hand geschrieben und geben den Stand der Hub-Doku wieder, nicht den Live-Zustand. Nach größeren Änderungen am Hub `CONTEXT.md` und `STATUS.md` aktualisieren.

## Datenschutz
Dieses Repo enthält bewusst keine Zugangsdaten, Token, internen Adressen, Namen von Personen, Inhalte aus dem Gehirn und nichts zu Kindern oder Gesundheit. Vor einer Veröffentlichung trotzdem noch einmal durchsehen.
